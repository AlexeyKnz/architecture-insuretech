### 1. Тип хранилища: PostgreSQL
- Отслеживание состояния заявок (created, pending, completed)
- Хранение таймаутов (60 секунд)
- Логирование для аудита и повтора запросов
### 2. API 
#### Kafka (+gRPC для статусов)
- Обработка 2500 RPS без блокировки core-app
- Гарантированная доставка сообщений
- Возможность повторной обработки при ошибках
- Масштабируемость через партицирование
#### Можно использовать gRPC с буферизацией запросов в Redis
- менее надежно при пиковых нагрузках
### API для веб-приложения
- Протокол Server-Sent Events (SSE) 
SSE идеально подходит для передачи асинхронных обновлений о статусе заявки ОСАГО от core-app к веб-приложению.
#### Паттерны отказоустойчивости
- Circuit Breaker	osago-aggregator → страховые
- Rate Limiting	osago-aggregator → страховые	100 RPS на компанию
- Retry	osago-aggregator (Kafka consumer)	3 попытки с задержкой
#### Учет экземпляров 
- Партицирование по request_id гарантирует обработку одной заявки одним подом
- Горизонтальное масштабирование без изменений архитектуры
